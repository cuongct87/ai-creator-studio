# ZUNVA / AI Creator Studio — Working Rules

Project: AI Creator Studio v1.5 Beta (future brand: ZUNVA). The founder is not a programmer: explain results in plain Vietnamese, keep code in English.

## Hard rules
1. One small task at a time. Show the visible result and acceptance criteria.
2. Read existing code first. Never rewrite the whole project, delete working features, or change framework/architecture without approval.
3. Before editing: create a git checkpoint/commit. After editing: list changed files, reason, diff summary, test commands and results.
4. Never put secrets/API keys in code, repo, logs or backups. Never call paid services or deploy to production without permission.
5. Keep AndroidImageSaver, existing handlers and current behavior intact.
6. Never mark a feature "done" without a test or founder confirmation. Do not claim features work unless tested.
7. If data is missing or a big risk appears, stop and report first.
8. Save credits: small, precise, verify each part.

## Product principles
- Local-first storage; AI is optional (basic design works without AI); BYOK, user pays the AI provider.
- Three entry points (AI / templates / blank) lead to one editor. Projects stay editable, not flat images.
